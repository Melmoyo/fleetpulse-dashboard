# FleetPulse Dashboard

A logistics operations dashboard built with React, TypeScript, and Recharts. Designed to give fleet managers a real-time overview of their operations in one place.

## Features

- 🚗 Live driver tracking and status monitoring
- 🗺️ Route management and delivery scheduling
- 📊 Delivery analytics with interactive charts
- ⛽ Fuel cost monitoring and reporting
- 🌙 Dark / light mode toggle
- 📐 Resizable panels for flexible layouts

## Tech Stack

- **React** — component-based UI
- **TypeScript** — type-safe codebase
- **Recharts** — data visualizations
- **Vite** — fast dev environment and build tool
- **TailwindCSS** — utility-first styling

## Getting Started

```bash
# Clone the repo
git clone https://github.com/Melmoyo/fleetpulse-dashboard.git

# Install dependencies
cd fleetpulse-dashboard
npm install

# Start the dev server
npm run dev
